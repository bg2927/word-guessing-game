# Word Guessing Game

## Overview

This project is a Python-based word guessing game developed using
Jupyter Notebook. 
Player has to attempt to guess a hidden word by
entering letters. 

## Design

The player receives information about their
guesses and continues playing until they correctly guess the word
or reach the maximum number of attempts.

## Data

The game uses a collection of words as possible answers. The selected
word is hidden from the player while they attempt to identify it.

## Algorithms

The program selects a word, accepts guesses from the player, checks
whether each guess is correct, and updates the game based on the
results.
